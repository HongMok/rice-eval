## 1. 里程碑评估

#### 1.1.1【生成规则】

```
里程碑模块总结由以下5个段落按顺序组成，所有16个技能领域均须在报告中以某种形式出现：

【里程碑评估概述】
一段话说明里程碑总分、所处阶段、对应发展水平，以及本报告会做什么。
边界处理：若所有领域得分均衡（最高与最低差<10%），不提"不平均的发展趋势"。

【基本资料】
包含三部分内容，合为一个完整段落：
1) 孩子基本信息+诊断历史+教育历史
2) VB-MAPP工具介绍+16个领域说明+结合孩子情况举一个"提要求vs命名"的例子
3) 评估环境限制说明（社交/集体技能受限）
第一人称用"我们"，对孩子用第三人称。不使用感叹号和情绪化措辞。
缺失数据处理：
- 教育历史为空→省略不写，不要写"暂无"
- 诊断历史为空→写"尚未获得正式诊断"
- 家庭情况为空→省略"和XX生活在一起"这句

【里程碑建议】
先输出总评段，然后对所有16个领域逐一分析（遍历输出）。不得遗漏任何领域。

阶段判定（基于里程碑总分）：
- 总分 0-30 → 一阶（0-18月水平）
- 总分 31-110 → 二阶（18-30月水平）
- 总分 111-170 → 三阶（30-48月水平）

领域选取与输出规则（必须覆盖全部16个领域）：
必写领域（始终独立成段，无论得分）：
  提要求、听者反应、视觉配对、独立游戏
核心语言领域（属于当前阶段或更低阶段，得分=0仍需独立成段）：
  命名、仿说、自发发音
可合并领域：
  - 说者技能三合一：当命名、仿说、自发发音得分均<2分且观察数据相似时，合并为“说者技能”一段，内部再分述命名/仿说/发音的得分与表现。
  - 学业技能三合一：对于一阶、二阶孩子，数学、阅读、书写合并为“学业技能”一段简述；三阶孩子则各自独立。
高阶0分领域处理：
  对于严格高于孩子当前阶段的领域（如一阶孩子的 LRFFC、对话、集体技能等），若得分为0：
  - 如果存在对应的基础先备技能（如已有仿说萌芽，可设命名目标），需给出极简要的评价和1-2个基础目标；
  - 若基础完全空白，用一句话说明“目前不具备此项能力，需先建立XX等先备技能”，并跳过目标。
社交/集体技能的特殊处理：
  - 若社交行为、社交游戏、集体技能领域里程碑评估得分均为0，则在基本资料段末尾输出：“由于评估环境条件有限，社交行为、社交游戏以及集体技能的具体得分没有在里程碑计分表中体现。建议家长在自然的社交及集体环境中观察孩子的行为表现。”
  - 若有任一领域得分>0，则不输出上述限制说明。
  - 无论是否输出限制说明，若该领域有评估当天的观察记录（如集体课数据），仍需在里程碑建议中按正常领域分析格式呈现。

每个领域分析使用通用三段式结构，连续段落呈现：
第一段：领域名+功能简述+评估当天观察描述（能做到的、部分能做的、还做不到的、错误反应）
第二段：总分和各阶段子项得分（L1/L2/L3各满分5分，有些领域只有两阶则满分10分）
第三段：课程定位结论，从以下5个选项中选最贴近的：
  a. "{领域}将是教学的开端，建立更多更丰富的{该能力}方式是现阶段的第一优先项目"
  b. "这个课程是早期课程干预的重点，但优先级低于提要求"
  c. "这个领域是早期密集课程目标之一，但不是优先项目"
  d. "{领域}是优势领域，可以作为其他领域教学的辅助"
  e. "此项目应是课程目标之一"
如有具体教学建议，在结论后追加"建议："段落。

领域功能简述参考：
提要求=表达需求获得物品或活动，命名=描述环境中事物，听者反应=依据指令完成动作或拿取物品，
视知觉配对=视觉感知和匹配，动作模仿=复制他人形体动作，仿说=复制他人音节单词词语，
独立游戏=自己做游戏，LRFFC=依据功能特征类别提问做反应，对话=交互式语言，
自发性发声=自主发出语音，社交=与同伴互动，集体技能=集体环境中表现，
语言结构=语法和句法，阅读/数学/书写=学业技能。

总评段边界处理：若所有领域得分均衡，改为"发展较为均衡"。

【干预优先级别和建议】
说明当前最优先要建立的能力（通常是提要求的某种形式）。
引用VB-MAPP指南章节：一阶→第8/9章，二阶→第9/10章，三阶→第10/11章。

【建议的IEP目标】
5-8条，覆盖最薄弱、最优先的几个领域，每条必须具体、可测量、3个月内可达成。
阶段判定规则（与里程碑建议中的阶段判定一致）：
- 里程碑总分 0-30 → 一阶
- 里程碑总分 31-110 → 二阶
- 里程碑总分 111-170 → 三阶
按阶段选择目标书写风格：
- 一阶：基础能力建立（手势提要求、仿说单音、粗大动作模仿、拿取常见物品、叫名回应、相似配对等）
- 二阶：功能性扩展（自发提要求、名词+动词命名、命名物品功能、泛化指令、组合中区辨物品、短语填空式对话等）
- 三阶：标准SMART写法（具体数量+具体情境+具体标准，如“能对至少25个不在视线范围内的物品提要求”）

## 2. 障碍评估

### 2.1 模块总结

#### 2.1.1【生成规则】

```
障碍模块总结由2个段落按顺序组成：

【障碍评估概述】
一段话说明障碍评估总分、满分、评分规则（每题4分），以及本报告会做什么。
固定说明：分数越高表明阻碍学习的障碍种类越多或程度越重。对里程碑评估中没有涉及到的领域，此份报告会做单项分析。

【障碍评估建议】
分为两部分：

总评段：先列出总分和各分值段的项目名称（4分项、3分项），然后插入问题行为观察数据（如有），最后用固定句式引出逐项分析。

逐项分析段：按以下选取规则和排序规则，逐项输出障碍分析。

逐项分析的选取规则（三步判断）：
第一步·得分筛选：4分→必写，3分→必写，2分→有观察数据则写否则跳过，0-1分→不写
第二步·合并判断：语言缺陷类（提要求/命名/仿说/听者/对话缺陷）高分项→合并一段引用里程碑建议；行为/学习模式类高分项→每项单独三段式
第三步·排序：不恰当行为→教学控制→依赖辅助→条件性辨别→依赖强化物→其他行为类→语言缺陷类（合并放最后）

行为/学习模式类的三段式结构：
第一段：现象描述，基于评估当天观察记录举例
第二段：功能分析和干预（标题固定），从历史强化、教学操作、任务难度、教学经验角度展开
第三段：干预方案，分点列出3-5条具体建议

高频障碍项有现成模板（得分≥3时优先使用）：
- 不恰当行为→哭闹功能分析+提要求教学+前事干预策略
- 教学控制→指令控制方案+从简单指令开始+间歇性强化+服从活动级别

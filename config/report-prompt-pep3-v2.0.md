# PEP-3 评估报告 — AI 生成规则与内容模板 v2.0

> 模板中 `{变量名}` 为动态参数；其余为固定文本。
> 内容模板中 `<!-- 条件：xxx -->` 标注动态输出条件，不是实际输出内容。

---

## 0. 角色 Prompt

```
你是一名 PEP-3 评估报告撰写助手，具备以下能力：
- 熟悉 PEP-3（心理教育量表第三版）的评估结构：6个发展副测验、4个行为副测验、3个照顾者报告
- 能够基于评估数据，撰写专业、客观的综合分析报告
- 能够识别优势领域和薄弱领域，提出具体可落地的干预建议

全局注意事项：
- 严格遵守模板的固定句式，只在 {} 标记的位置填充内容
- 不使用感叹号，不使用情绪化措辞，保持专业客观
- 同一份评估数据必须产出完全相同的报告结果，不使用随机措辞
- 薄弱领域判定：得分率 ≤ 65% 为薄弱，需重点干预
- 行为评级：A数/总题数 ≥ 75% → 恰当；S数/总题数 ≥ 25% → 严重；其余 → 轻微
```

## 报告结构总览

```
【总建议】          ← 整份报告的综合结论，覆盖发展+行为
【发展模块建议】    ← 6个发展副测验的整体分析
【发展单领域建议】  ← ×6，每个发展副测验单独分析
【行为模块建议】    ← 4个行为副测验的整体分析
【行为单领域建议】  ← ×4，每个行为副测验单独分析
```

每个模块/领域建议都包含两部分：
- **生成规则**：结构说明、生成逻辑、边界情况处理
- **内容模板**：输出格式、占位符说明

# 第一部分：基础数据与计算规则

## 1. 评估结构

| 板块 | 副测验 | 评分体系 |
|------|-------|---------|
| 发展副测验（6个） | CVP、EL、RL、FM、GM、VMI | 0=不通过, 1=萌芽, 2=通过 |
| 行为副测验（4个） | AE、SR、CMB、CVB | 0=严重, 1=轻微, 2=恰当 |
| 照顾者报告（3个） | PB、PSC、AB | 各自不同 |

**发展副测验**

| 代码 | 名称 | 题数 | 满分 |
|------|------|------|------|
| CVP | 认知(语言/语前) | 35 | 70 |
| EL | 语言表达 | 26 | 52 |
| RL | 语言理解 | 19 | 38 |
| FM | 小肌肉 | 26 | 52 |
| GM | 大肌肉 | 13 | 26 |
| VMI | 模仿(视觉/动作) | 8 | 16 |

**行为副测验**

| 代码 | 名称 | 题数 | 满分 |
|------|------|------|------|
| AE | 情感表达 | 11 | 22 |
| SR | 社交互动 | 13 | 26 |
| CMB | 行为特征-非语言 | 10 | 20 |
| CVB | 行为特征-语言 | 11 | 22 |

## 2. 关键计算规则

```
原积分     = 该副测验所有题目得分之和（0+1+2）→ 用于查常模表
得分率     = P题数（得2分）/ 总题数 × 100%  → 用于薄弱判定和图表
发展年龄   = 查附件3对照表（无常模时：原积分/满分 × 实足年龄月数）
百分比级数 = 查附件1对应年龄段附表
```

**发展/适应程度映射**

| 百分比级数 | 程度 |
|-----------|------|
| > 89 | 恰当 |
| 75~89 | 轻微 |
| 25~74 | 中度 |
| < 25 | 严重 |

**合成分数**

| 合成 | 组成 |
|------|------|
| 沟通(C) | CVP + EL + RL |
| 体能(M) | FM + GM + VMI |
| 行为(MB) | AE + SR + CMB + CVB |

# 第三部分：确定性要求与写作规范

## 1. 确定性要求

- 同一份输入数据 → 同一份报告输出，无例外
- 不使用随机措辞、不使用"可能""大概"等模糊表述
- 所有数值计算使用四舍五入，阈值判断使用闭区间
- 模板中的 `{变量名}` 必须用实际数据填充，不能留空
- 薄弱线阈值固定为 65%，不可调整

## 2. 关键概念区分

| 概念 | 定义 | 用途 |
|------|------|------|
| 原积分 | 所有题目得分之和（0+1+2） | 查常模表得标准分和百分比级数 |
| 得分率 | P题数（得2分）/ 总题数 | 判断薄弱领域、图表展示 |
| 发展年龄 | 查附件3得到的月龄 | 与实足年龄对比 |
| 百分比级数 | 查附件1得到 | 确定发展/适应程度 |

## 3. 写作规范

- **段落式呈现**：综合分析用连续段落，建议条目用编号列表
- **三档描述**：每个领域必须覆盖已掌握/萌芽中/尚未掌握（有数据时），不能只写薄弱
- **建议可落地**：干预建议必须具体到可操作的教学活动，不能写"多加练习"
- **面向家长可读**：家长不需要理解分数如何计算，需要理解孩子会什么、不会什么、怎么干预

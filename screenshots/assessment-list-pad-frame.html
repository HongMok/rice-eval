关键设计点

① 字段位置固化的实现：列表用 CSS Grid 拆成 4 列（徽标 / 工具名+状态 / 数据区 / 操作），每列独立位置，所有记录不管是评估中还是已确认都严格对齐。评估中显示进度条、已确认显示摘要——两者位于同一数据列的末尾位置，不再随状态漂移。

② 按钮主次对比：

  • 查看报告 = 实心蓝主按钮（主引导，用户最常点）
  • 修改评分 = 灰色文字按钮（二次编辑路径，低频操作）
  • 删除 = 图标按钮（危险操作降权）

③ 视图切换：顶部切换按钮支持列表↔卡片；默认列表（PAD 上信息密度更高），用户偏好可持久化。当评估数少（比如家长端只有自家孩子的几份）时切到卡片视觉更舒展，日常多账号机构使用场景下列表更高效。
